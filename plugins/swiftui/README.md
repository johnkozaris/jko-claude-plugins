# SwiftUI

Lightweight, opinionated guidance for decisions that genuinely depend on
SwiftUI and Apple-platform behavior.

The skill carries a small set of positions about state ownership, view
identity, navigation, concurrency, and platform fit. Detailed material remains
in references and is loaded only when the code signals that topic.

Where the host exposes plugin commands, use `/swift-critique <target>` for an
explicit review workflow. Otherwise request the review directly. Use a runtime
validator when appearance or interaction must be observed.
